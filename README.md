# José Brenes — Professional Portfolio

Static bilingual portfolio for GitHub Pages.

## Files

- `index.html`: English site
- `es.html`: Spanish site
- `styles.css`: responsive design and themes
- `script.js`: mobile navigation, theme toggle, and animations
- `assets/images/`: profile and project dashboard previews
- `assets/resume/`: public data-analytics CVs
- `.nojekyll`: disables Jekyll processing for the static site

## Publishing

1. Copy all files in this folder into the root of `josebrenesc.github.io`.
2. Commit to `main`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Visit `https://josebrenesc.github.io`.

## Portfolio disclosure

All companies, customers, transactions, agents, and operational results in the
analytics projects are synthetic. Employment history represents real professional
experience.
